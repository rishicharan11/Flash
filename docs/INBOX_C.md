## Run locally

Requires Node.js 22.12 or newer. npm ci also installs the Husky Git hooks.

```sh
npm ci
npm run dev
```

Open the printed local URL. The source route /lab/t/inbox/C also resolves through
Vite's frontend fallback. Production output is generated by npm run build.
Use npm run preview to inspect that output.

## Verify

```sh
npx playwright install chromium
npm test
```

Tests start and stop their own local Vite server. Desktop and mobile screenshots
are written under ignored test-results directories.

## What is implemented

The source sidebar, header, conversation list and empty-state artwork are
recreated with the original source SVG icons, PNG assets and local fonts.
Search, All/Read/Unread/Attachments filters, reading and closing conversations,
marking unread, local deletion, replies, templates, attachment filenames,
customer selection, mobile navigation and keyboard controls work locally.

The starting data has 12 conversations: 5 read, 7 unread and 4 with attachments.
The captured Rishi conversation matches the source text. Other message bodies
and templates are demo content based on the captured subjects.

Sending only adds a message to this browser session's demo state. It does not
send email, upload files, call a backend or persist changes after reload.
Other workspace destinations provide scope feedback and do not open new pages.

## Design and source files

- index.html: captured shell, inbox, customer modal and original SVG sprite.
- src/main.js: interaction state and event handling.
- src/data.js: source-grounded demo contacts and conversations.
- src/styles.css: original CSS cascade with local fonts and one menu repair.
- public/assets and public/fonts: original images and font files stored locally.
- design/*.jsx: editable Paper exports translated to local asset URLs.
- design/inbox-c-styles.json: exact computed Paper frame/component styles.
- tests/inbox.spec.js: browser interaction and responsive checks.
- design-qa.md: source comparison and validation record.

The Paper exports preserve the reviewed fixed frames. The runtime uses the
source's responsive CSS. Unused source-page CSS selectors remain to preserve
mixed-selector rules and the original layered cascade; those pages are not built.

One scoped repair positions the conversation-header actions menu downward,
keeping its options clickable without changing the initial screen.
